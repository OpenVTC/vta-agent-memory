Search the user's VTA-backed memory for: $ARGUMENTS

Use `memory_recall` with that as the query. With no argument, recall with no
query to get the most recently updated memories.

Read the summaries, then `memory_get` only the one or two that actually matter —
not all of them. Summarise what you found in a few lines, naming the keys so the
user can refer to them. If nothing matched, say so plainly rather than reporting
the least-irrelevant results.
